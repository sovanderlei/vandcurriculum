## Sobre este projeto

Este repositório é o código-fonte do currículo, feito em **React** e publicado no **GitHub Pages**.

O conteúdo do currículo fica em arquivos JSON, separados do código:

| Arquivo | Conteúdo |
| --- | --- |
| [`public/data/curriculo-pt.json`](public/data/curriculo-pt.json) | Versão em português |
| [`public/data/curriculo-en.json`](public/data/curriculo-en.json) | Versão em inglês |
| [`public/img/foto.png`](public/img/foto.png) | Foto |

Para atualizar o currículo, basta editar esses arquivos e publicar de novo.

### Rodar localmente

```bash
npm install
npm start          # abre em http://localhost:3000
```

### Publicar no GitHub Pages

```bash
npm run deploy     # gera o build e envia para o branch gh-pages
```

O site fica em https://sovanderlei.github.io/vandcurriculum/

> A pasta `angular-legacy/` guarda a versão antiga do currículo, feita em Angular.
